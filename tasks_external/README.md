# External Evaluation Tasks

This directory contains external benchmarks and evaluation tasks that are not supported in LM-Eval-Harness.

## Available Benchmarks

### [ALBA](alba/)
**ALBA: A European Portuguese Benchmark for Evaluating Language and Linguistic Dimensions in Generative LLMs**

A benchmark designed to systematically evaluate generative large language models (LLMs) across linguistic and language-specific dimensions in European Portuguese.

- Paper: [ACL Anthology](https://aclanthology.org/2026.propor-1.69/)
- Updated Repository: [github.com/AMALIA-LLM/alba-benchmark](https://github.com/AMALIA-LLM/alba-benchmark)
- Presented at PROPOR 2026

### [P3B3](p3b3/)
**P3B3: A Multi-Turn Conversational Benchmark for Measuring European and Brazilian Portuguese Variety Bias in LLMs**

A benchmark for evaluating language model biases toward Portuguese language variants (European Portuguese vs Brazilian Portuguese) through multi-turn conversation generation and automated assessment.

- Paper: [arXiv:2606.16753](https://arxiv.org/abs/2606.16753)
- Updated Repository: [github.com/AMALIA-LLM/p3b3-benchmark](https://github.com/AMALIA-LLM/p3b3-benchmark)
- Presented at MeLLM Workshop @ ACL 2026

## Usage

Each benchmark has its own evaluation scripts and requirements. Please refer to the individual README files in each subdirectory for detailed setup and usage instructions.
